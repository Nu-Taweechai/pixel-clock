HOW IT WORKS
UP/DN TREND = ADX และ ER สูงพอ + EMA20/50 กับ +DI/-DI ชี้ทางเดียวกัน | SIDEWAY = ADX ต่ำ หรือราคาแกว่งไปมา | WEAK = กลางๆ หรือสัญญาณขัดกัน | กรอบทอง ALIGN = M5 กับ M15 เทรนทางเดียวกัน
ตัวเลขใต้ป้าย = ADX / ER ใช้เฉพาะแท่งที่ปิดแล้ว M15 รวมจากแท่ง M5 ข้อมูลจาก Yahoo Finance ผ่าน Worker อาจต่างจากราคาโบรกเกอร์เล็กน้อยและหน่วงได้
เป็นการจัดกลุ่มสภาพตลาดเท่านั้น ไม่ใช่สัญญาณซื้อขาย | ปรับเกณฑ์ที่ SET > FOREX SCAN | ตลาดปิดสุดสัปดาห์แถวจะจาง
